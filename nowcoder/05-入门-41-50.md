## 第 41 题 · 自定义函数 add

### 【题目描述】
编写函数 `int add(int x, int y)`，返回两数之和。主函数读入两个整数并调用该函数输出结果。

### 【输入描述】
一行，两个整数 $a$ 和 $b$（$-10^9 \le a,b \le 10^9$）。

### 【输出描述】
一行，输出 $a+b$。

### 【输入样例】
```
2 7
```

### 【输出样例】
```
9
```

### 【提示】
本题重点是练习函数定义与调用。若担心溢出，参数可用 `long long`（本参考代码按题面用 `int` 演示函数结构；实际求和仍用 `long long` 更稳妥）。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

// 返回两数之和
long long add(long long x, long long y) {
    return x + y;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long a, b;
    cin >> a >> b;
    cout << add(a, b) << '\n';
    return 0;
}
```

## 第 42 题 · 自定义函数 max2

### 【题目描述】
编写函数返回两个整数中的较大值。主函数读入两个整数并输出较大值。

### 【输入描述】
一行，两个整数 $a$ 和 $b$（$-10^9 \le a,b \le 10^9$）。

### 【输出描述】
一行，输出较大值。

### 【输入样例】
```
8 3
```

### 【输出样例】
```
8
```

### 【提示】
两数相等时返回该数即可。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

long long max2(long long x, long long y) {
    return x > y ? x : y;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long a, b;
    cin >> a >> b;
    cout << max2(a, b) << '\n';
    return 0;
}
```

## 第 43 题 · 判断是否为偶数（bool 函数）

### 【题目描述】
编写返回 `bool` 的函数，判断一个整数是否为偶数。主函数读入一个整数：若为偶数输出 `yes`，否则输出 `no`。

### 【输入描述】
一行，一个整数 $n$（$-10^9 \le n \le 10^9$）。

### 【输出描述】
一行，输出 `yes` 或 `no`。

### 【输入样例】
```
-4
```

### 【输出样例】
```
yes
```

### 【提示】
偶数判断用 `n % 2 == 0`。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

bool isEven(long long n) {
    return n % 2 == 0;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << (isEven(n) ? "yes" : "no") << '\n';
    return 0;
}
```

## 第 44 题 · 函数求 1 到 n 的和

### 【题目描述】
编写函数计算 $1+2+\cdots+n$，主函数读入 $n$ 并输出结果。

### 【输入描述】
一行，一个正整数 $n$（$1 \le n \le 10^6$）。

### 【输出描述】
一行，输出累加和。

### 【输入样例】
```
100
```

### 【输出样例】
```
5050
```

### 【提示】
函数内部可用循环或公式。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

long long sumTo(long long n) {
    long long s = 0;
    for (long long i = 1; i <= n; i++) {
        s += i;
    }
    return s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << sumTo(n) << '\n';
    return 0;
}
```

## 第 47 题 · 大写转小写

### 【题目描述】
输入一个大写字母，将其转换为对应的小写字母并输出。保证输入一定是大写字母。

### 【输入描述】
一行，一个大写字母。

### 【输出描述】
一行，输出对应的小写字母。

### 【输入样例】
```
B
```

### 【输出样例】
```
b
```

### 【提示】
可用 `c - 'A' + 'a'`，或 `c + 32`。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    char c;
    cin >> c;
    // ASCII：大写转小写
    c = c - 'A' + 'a';
    cout << c << '\n';
    return 0;
}
```

## 第 50 题 · 函数求数组最大值

### 【题目描述】
编写函数，接收数组与长度，返回数组最大值。主函数读入 $n$ 和 $n$ 个整数后调用该函数输出结果。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。  
第二行 $n$ 个整数（每个数绝对值不超过 $10^9$）。

### 【输出描述】
一行，输出最大值。

### 【输入样例】
```
4
-3 8 0 5
```

### 【输出样例】
```
8
```

### 【提示】
数组名作为函数参数时，通常还需要传入长度。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

long long arrayMax(const long long a[], int n) {
    long long mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > mx) mx = a[i];
    }
    return mx;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    long long a[1000];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    cout << arrayMax(a, n) << '\n';
    return 0;
}
```

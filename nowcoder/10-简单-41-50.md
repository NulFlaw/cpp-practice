## 第 41 题 · 统计单词个数

### 【题目描述】
输入一行英文句子，单词之间由空格分隔，统计单词个数。

### 【输入描述】
一行字符串（长度不超过 $1000$）。

### 【输出描述】
一行，输出单词个数。

### 【输入样例】
```
I love C++
```

### 【输出样例】
```
3
```

### 【提示】
可用 `stringstream` 分割。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s, w;
    getline(cin, s);
    stringstream ss(s);
    int cnt = 0;
    while (ss >> w) cnt++;
    cout << cnt << '\n';

    return 0;
}
```

## 第 42 题 · 去重保留首次顺序

### 【题目描述】
输入 $n$ 个整数，输出去重后的序列，保留每个数第一次出现的顺序。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出去重后的序列。

### 【输入样例】
```
7
1 2 1 3 2 4 1
```

### 【输出样例】
```
1 2 3 4
```

### 【提示】
可用标记数组或双重循环判断是否出现过。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a, res;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        a.push_back(x);
    }
    for (int i = 0; i < n; i++) {
        bool seen = false;
        for (int j = 0; j < i; j++) {
            if (a[j] == a[i]) { seen = true; break; }
        }
        if (!seen) res.push_back(a[i]);
    }
    for (int i = 0; i < (int)res.size(); i++) {
        if (i) cout << ' ';
        cout << res[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 43 题 · 空心正方形

### 【题目描述】
输入正整数 $n$，打印 $n$ 行空心正方形星号图案（边框为 `*`，内部为空格）。

### 【输入描述】
一行，一个正整数 $n$（$2 \le n \le 50$）。

### 【输出描述】
共 $n$ 行图案。

### 【输入样例】
```
4
```

### 【输出样例】
```
****
*  *
*  *
****
```

### 【提示】
边界位置输出 `*`，否则输出空格。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (i == 0 || i == n - 1 || j == 0 || j == n - 1) cout << '*';
            else cout << ' ';
        }
        cout << '\n';
    }

    return 0;
}
```

## 第 44 题 · 质因数分解

### 【题目描述】
输入正整数 $n$，输出它的质因数分解（按从小到大，重复质因数重复输出），数字之间用空格隔开。

### 【输入描述】
一行，一个正整数 $n$（$2 \le n \le 10^{12}$）。

### 【输出描述】
一行，输出所有质因数。

### 【输入样例】
```
12
```

### 【输出样例】
```
2 2 3
```

### 【提示】
从 $2$ 开始试除。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n;
    cin >> n;
    bool first = true;
    for (long long i = 2; i * i <= n; i++) {
        while (n % i == 0) {
            if (!first) cout << ' ';
            cout << i;
            first = false;
            n /= i;
        }
    }
    if (n > 1) {
        if (!first) cout << ' ';
        cout << n;
    }
    cout << '\n';

    return 0;
}
```

## 第 45 题 · 大整数竖式加法（非负）

### 【题目描述】
输入两个非负大整数（以字符串形式，长度可达 $1000$），输出它们的和。

### 【输入描述】
一行，两个非负整数字符串 $a,b$（不含前导零，除非本身为 $0$）。

### 【输出描述】
一行，输出和（不含前导零，除非结果为 $0$）。

### 【输入样例】
```
999 1
```

### 【输出样例】
```
1000
```

### 【提示】
按位从低到高相加并处理进位。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string a, b;
    cin >> a >> b;
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    string r;
    int carry = 0;
    for (int i = 0; i < (int)max(a.size(), b.size()) || carry; i++) {
        int sum = carry;
        if (i < (int)a.size()) sum += a[i] - '0';
        if (i < (int)b.size()) sum += b[i] - '0';
        r += char('0' + sum % 10);
        carry = sum / 10;
    }
    reverse(r.begin(), r.end());
    cout << r << '\n';

    return 0;
}
```

## 第 46 题 · 相邻差值最大值

### 【题目描述】
输入 $n$ 个整数，求相邻两个元素差的绝对值的最大值。

### 【输入描述】
第一行一个整数 $n$（$2 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出最大相邻差。

### 【输入样例】
```
5
1 5 2 9 3
```

### 【输出样例】
```
7
```

### 【提示】
$|2-9|=7$ 最大。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int mx = 0;
    for (int i = 1; i < n; i++) {
        int d = abs(a[i] - a[i - 1]);
        if (d > mx) mx = d;
    }
    cout << mx << '\n';

    return 0;
}
```

## 第 47 题 · 只保留字母

### 【题目描述】
输入一行字符串，删除所有非字母字符后输出。

### 【输入描述】
一行字符串（长度不超过 $1000$）。

### 【输出描述】
一行，输出只含字母的字符串。

### 【输入样例】
```
H3ll0, W0rld!
```

### 【输出样例】
```
HllWrld
```

### 【提示】
用 `isalpha` 过滤。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s, r;
    getline(cin, s);
    for (size_t i = 0; i < s.size(); i++) {
        if (isalpha((unsigned char)s[i])) r += s[i];
    }
    cout << r << '\n';

    return 0;
}
```

## 第 48 题 · 第二大元素（不重复）

### 【题目描述】
输入 $n$ 个整数，求严格第二大的元素。保证至少存在两个不同的数。

### 【输入描述】
第一行一个整数 $n$（$2 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出第二大元素。

### 【输入样例】
```
5
5 5 3 1 4
```

### 【输出样例】
```
4
```

### 【提示】
维护最大值与次大值，注意跳过与最大值相等的数。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    long long first = -1e18, second = -1e18;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (x > first) {
            second = first;
            first = x;
        } else if (x > second && x != first) {
            second = x;
        }
    }
    cout << second << '\n';

    return 0;
}
```

## 第 49 题 · 矩阵转置

### 【题目描述】
输入一个 $n$ 行 $m$ 列矩阵，输出它的转置矩阵。

### 【输入描述】
第一行两个整数 $n,m$（$1 \le n,m \le 100$）。
接下来 $n$ 行，每行 $m$ 个整数。

### 【输出描述】
输出 $m$ 行，每行 $n$ 个整数。

### 【输入样例】
```
2 3
1 2 3
4 5 6
```

### 【输出样例】
```
1 4
2 5
3 6
```

### 【提示】
转置后第 $j$ 行第 $i$ 列为原矩阵第 $i$ 行第 $j$ 列。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    cin >> n >> m;
    vector<vector<int> > a(n, vector<int>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];
    for (int j = 0; j < m; j++) {
        for (int i = 0; i < n; i++) {
            if (i) cout << ' ';
            cout << a[i][j];
        }
        cout << '\n';
    }

    return 0;
}
```

## 第 50 题 · 3×3 矩阵求和

### 【题目描述】

### 【输入描述】

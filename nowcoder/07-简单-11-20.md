## 第 11 题 · 数组逆序输出

### 【题目描述】
输入 $n$ 和 $n$ 个整数，按逆序输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，逆序输出数组元素。

### 【输入样例】
```
4
1 2 3 4
```

### 【输出样例】
```
4 3 2 1
```

### 【提示】
$n=1$ 时输出该元素即可。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = n - 1; i >= 0; i--) {
        if (i < n - 1) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 12 题 · 数组右移一位

### 【题目描述】
将数组整体向右循环移动一位：最后一个元素移到最前面。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出右移后的数组。

### 【输入样例】
```
5
1 2 3 4 5
```

### 【输出样例】
```
5 1 2 3 4
```

### 【提示】
$n=1$ 时数组不变。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int last = a[n - 1];
    for (int i = n - 1; i > 0; i--) a[i] = a[i - 1];
    a[0] = last;
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    return 0;
}
```

### 【输入样例】

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
```

## 第 14 题 · 冒泡排序

### 【题目描述】
输入 $n$ 和 $n$ 个整数，使用冒泡排序从小到大排序后输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出排序后的数组。

### 【输入样例】
```
5
5 1 4 2 3
```

### 【输出样例】
```
1 2 3 4 5
```

### 【提示】
练习冒泡排序过程，不要直接调用 `sort`（本题参考实现为冒泡）。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    // 冒泡排序
    for (int i = 0; i < n; i++) {
        for (int j = 0; j + 1 < n - i; j++) {
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
        }
    }
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 15 题 · 选择排序

### 【题目描述】
输入 $n$ 和 $n$ 个整数，使用选择排序从小到大排序后输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出排序后的数组。

### 【输入样例】
```
5
5 1 4 2 3
```

### 【输出样例】
```
1 2 3 4 5
```

### 【提示】
每轮选未排序区间的最小值放到前面。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++) {
        int mn = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[mn]) mn = j;
        }
        swap(a[i], a[mn]);
    }
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 16 题 · 合并两个数组

### 【题目描述】
输入两个数组，长度分别为 $n$ 和 $m$，按输入顺序合并后输出。

### 【输入描述】
第一行两个整数 $n,m$（$1 \le n,m \le 500$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出合并后的数组。

### 【输入样例】
```
3 2
1 2 3
4 5
```

### 【输出样例】
```
1 2 3 4 5
```

### 【提示】
先输出第一个数组，再输出第二个数组。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>

#include <iomanip>
using namespace std;

    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    cin >> n >> m;
    vector<int> a(n), b(m);
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < m; i++) cin >> b[i];
    bool first = true;
    for (int i = 0; i < n; i++) {
        if (!first) cout << ' ';
```

## 第 17 题 · 删除等于 x 的元素

### 【题目描述】
输入数组和一个整数 $x$，删除数组中所有等于 $x$ 的元素，按原相对顺序输出剩余元素。若删完为空，输出空行。

### 【输入描述】
第一行两个整数 $n,x$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出删除后的数组；若为空则输出空行。

### 【输入样例】
```
6 2
1 2 3 2 4 2
```

### 【输出样例】
```
1 3 4
```

### 【提示】
可用新数组收集不等于 $x$ 的元素。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, x;
    cin >> n >> x;
    vector<int> res;
    for (int i = 0; i < n; i++) {
        int v;
        cin >> v;
        if (v != x) res.push_back(v);
    }
    for (int i = 0; i < (int)res.size(); i++) {
        if (i) cout << ' ';
        cout << res[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 19 题 · 统计每个元素出现次数

### 【题目描述】
输入 $n$ 个整数，按元素从小到大的顺序，输出每个不同元素及其出现次数。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数（绝对值不超过 $10^6$）。

### 【输出描述】
若干行，每行两个整数：数值 出现次数。

### 【输入样例】
```
6
1 2 1 3 2 1
```

### 【输出样例】
```
1 3
2 2
3 1
```

### 【提示】
可用排序后扫描，或双重循环（$n$ 不大）。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    for (int i = 0; i < n; ) {
        int j = i;
        while (j < n && a[j] == a[i]) j++;
        cout << a[i] << ' ' << (j - i) << '\n';
        i = j;
    }

    return 0;
}
```

## 第 20 题 · 奇数前偶数后

### 【题目描述】
将数组中奇数放到前面，偶数放到后面，相对顺序不做要求。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出调整后的数组。

### 【输入样例】
```
6
1 2 3 4 5 6
```

### 【输出样例】
```
1 3 5 2 4 6
```

### 【提示】
样例仅作一种合法输出参考；只要奇数都在偶数前即可。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> odd, even;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x % 2 != 0) odd.push_back(x);
        else even.push_back(x);
    }
    bool first = true;
    for (int i = 0; i < (int)odd.size(); i++) {
        if (!first) cout << ' ';
        cout << odd[i];
        first = false;
    }
    for (int i = 0; i < (int)even.size(); i++) {
        if (!first) cout << ' ';
        cout << even[i];
        first = false;
    }
    cout << '\n';

    return 0;
}
```

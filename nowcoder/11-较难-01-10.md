## 第 1 题 · vector 排序去重

### 【题目描述】
读入 $n$ 个整数，排序并去重后输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 10^5$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出排序去重后的序列。

### 【输入样例】
```
6
3 1 2 1 3 2
```

### 【输出样例】
```
1 2 3
```

### 【提示】
先 `sort` 再 `unique`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    a.erase(unique(a.begin(), a.end()), a.end());
    for (int i = 0; i < (int)a.size(); i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 2 题 · map 统计单词

### 【题目描述】
读入 $n$ 个单词，统计每个单词出现次数，按字典序输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 10^5$）。
第二行 $n$ 个单词（仅小写字母，长度不超过 $20$）。

### 【输出描述】
若干行，每行：单词 次数。

### 【输入样例】
```
5
apple banana apple orange banana
```

### 【输出样例】
```
apple 2
banana 2
orange 1
```

### 【提示】
使用 `map<string,int>`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    map<string, int> cnt;
    for (int i = 0; i < n; i++) {
        string w;
        cin >> w;
        cnt[w]++;
    }
    for (map<string, int>::iterator it = cnt.begin(); it != cnt.end(); ++it) {
        cout << it->first << ' ' << it->second << '\n';
    }

    return 0;
}
```

## 第 3 题 · set 去重排序

### 【题目描述】
读入一串数字，存入 `set` 后输出集合中的元素。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 10^5$）。
第二行 $n$ 个整数。

### 【输出描述】

### 【输入样例】
```
5
4 2 4 1 2
```

### 【输出样例】
```

```

### 【提示】

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
```

## 第 4 题 · 前缀和区间查询

### 【题目描述】
给定长度为 $n$ 的数组，有 $q$ 次询问，每次询问区间 $[l,r]$（$1$ 下标）的元素和。

### 【输入描述】
第一行两个整数 $n,q$（$1 \le n,q \le 10^5$）。
第二行 $n$ 个整数。
接下来 $q$ 行，每行两个整数 $l,r$。

### 【输出描述】
共 $q$ 行，每行一个区间和。

### 【输入样例】
```
5 3
1 2 3 4 5
1 3
2 5
3 3
```

### 【输出样例】
```
6
14
3
```

### 【提示】
预处理前缀和 $s[i]=s[i-1]+a[i]$，查询 $s[r]-s[l-1]$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, q;
    cin >> n >> q;
    vector<long long> s(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        s[i] = s[i - 1] + x;
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l - 1] << '\n';
    }

    return 0;
}
```

## 第 5 题 · 差分数组

### 【题目描述】
长度为 $n$ 的数组初始全为 $0$，进行 $q$ 次操作：将区间 $[l,r]$ 同时加上 $v$。输出最终数组。

### 【输入描述】
第一行两个整数 $n,q$（$1 \le n,q \le 10^5$）。
接下来 $q$ 行，每行三个整数 $l,r,v$（$1 \le l \le r \le n$）。

### 【输出描述】
一行，输出最终数组 $n$ 个整数。

### 【输入样例】
```
5 2
1 3 2
2 5 1
```

### 【输出样例】
```
2 3 3 1 1
```

### 【提示】
差分：$d[l]+=v$，$d[r+1]-=v$，再前缀还原。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, q;
    cin >> n >> q;
    vector<long long> d(n + 2, 0);
    while (q--) {
        int l, r, v;
        cin >> l >> r >> v;
        d[l] += v;
        d[r + 1] -= v;
    }
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];
        if (i > 1) cout << ' ';
        cout << d[i];
    }
    cout << '\n';

    return 0;
}
```

## 第 6 题 · 二分查找

### 【题目描述】
给定升序数组，二分查找目标值 $t$，找到则输出任意一个下标（$0$ 开始），否则输出 $-1$。

### 【输入描述】
第一行两个整数 $n,t$（$1 \le n \le 10^5$）。
第二行 $n$ 个升序整数。

### 【输出描述】
一行，输出下标或 $-1$。

### 【输入样例】
```
5 4
1 2 4 4 7
```

### 【输出样例】
```
2
```

### 【提示】
样例中下标 $2$ 或 $3$ 均可，本参考输出第一次找到的位置。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, t;
    cin >> n >> t;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int l = 0, r = n - 1, ans = -1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (a[mid] == t) { ans = mid; break; }
        else if (a[mid] < t) l = mid + 1;
        else r = mid - 1;
    }
    cout << ans << '\n';

    return 0;
}
```

## 第 7 题 · 二分答案：最小 x

### 【题目描述】
求最小的正整数 $x$，使得 $1+2+\cdots+x \ge S$。

### 【输入描述】
一行，一个正整数 $S$（$1 \le S \le 10^{18}$）。

### 【输出描述】
一行，输出最小的 $x$。

### 【输入样例】
```
10
```

### 【输出样例】
```
4
```

### 【提示】
因为 $1+2+3+4=10$。对 $x$ 二分，判断 $x(x+1)/2 \ge S$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long S;
    cin >> S;
    long long l = 1, r = 2e9, ans = 1;
    while (l <= r) {
        long long mid = (l + r) / 2;
        // 求最小 x 使 1+..+x >= S
        if (mid * (mid + 1) / 2 >= S) {
            ans = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }
    cout << ans << '\n';

    return 0;
}
```

## 第 8 题 · pair 按分数降序

### 【题目描述】
有 $n$ 名学生，每人有分数和姓名。按分数从高到低输出；分数相同则按输入顺序稳定即可（本参考按分数降序）。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 10^5$）。
接下来 $n$ 行，每行：分数 姓名。

### 【输出描述】
按排序后的顺序输出，每行：分数 姓名。

### 【输入样例】
```
3
90 Alice
100 Bob
90 Carol
```

### 【输出样例】
```
100 Bob
90 Alice
90 Carol
```

### 【提示】
使用 `vector<pair<int,string>>` + 自定义比较。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<pair<int, string> > a(n);
    for (int i = 0; i < n; i++) cin >> a[i].first >> a[i].second;
    // 按分数降序
    sort(a.begin(), a.end(), [](const pair<int, string>& x, const pair<int, string>& y) {
        return x.first > y.first;
    });
    for (int i = 0; i < n; i++) {
        cout << a[i].first << ' ' << a[i].second << '\n';
    }

    return 0;
}
```

## 第 10 题 · vector 模拟栈

### 【题目描述】
用 `vector` 模拟栈。操作：
- `push x`：入栈
- `pop`：出栈（栈空则忽略）
- `top`：输出栈顶（栈空输出 `-1`）
- `exit`：结束

### 【输入描述】
若干行操作，以 `exit` 结束。

### 【输出描述】
对每个 `top` 输出一行。

### 【输入样例】
```
push 1
push 2
top
pop
top
pop
top
exit
```

### 【输出样例】
```
2
1
-1
```

### 【提示】
用 `vector` 的 `push_back/pop_back/back`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    vector<int> st;
    string op;
    while (cin >> op) {
        if (op == "exit") break;
        if (op == "push") {
            int x;
            cin >> x;
            st.push_back(x);
        } else if (op == "pop") {
            if (!st.empty()) st.pop_back();
        } else if (op == "top") {
            if (st.empty()) cout << -1 << '\n';
            else cout << st.back() << '\n';
        }
    }

    return 0;
}
```

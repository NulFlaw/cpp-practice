## 建议做题顺序

1. 先完整做完 **入门 1～50**
2. 再做 **简单 1～50**
3. 较难 / 困难 按专题选做，配合 Core Guidelines 把代码写规范

## 在本仓库中练习

**推荐：打开网页题库（含样例验证）**

1. 双击运行 [`../start-verify.bat`](../start-verify.bat)
2. 浏览器打开 http://127.0.0.1:3789/
3. 选题 → 在【在线作答】写代码 → 点「提交验证」
4. 查看通过/未通过、期望输出与你的输出差异

**或直接读 Markdown**

1. 打开对应 md，复制参考代码（或自己写）
2. 粘贴到 `practice/src/main.cpp`
3. `Ctrl+Shift+B` 编译
4. 运行 `.\practice\build\practice.exe`，按样例输入验证

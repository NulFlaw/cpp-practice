## 第 21 题 · 直角三角形星号

### 【题目描述】
输入正整数 $n$，打印 $n$ 行直角三角形：第 $i$ 行有 $i$ 个 `*`。

### 【输入描述】
一行，一个正整数 $n$（$1 \le n \le 50$）。

### 【输出描述】
共 $n$ 行，第 $i$ 行输出 $i$ 个 `*`（无空格）。

### 【输入样例】
```
4
```

### 【输出样例】
```
*
**
***
****
```

### 【提示】
外层循环控制行，内层循环控制每行星号个数。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cout << '*';
        }
        cout << '\n';
    }
    return 0;
}
```

## 第 24 题 · 九九乘法表（左下三角）

### 【题目描述】
打印九九乘法表的左下三角版本。第 $i$ 行输出 $1\times i$ 到 $i\times i$ 的乘法算式，同一行内用制表符 `\t` 分隔。

### 【输入描述】
无输入。

### 【输出描述】
共 $9$ 行，格式如样例。

### 【输入样例】
```
（无）
```

### 【输出样例】
```
1x1=1
1x2=2	2x2=4
1x3=3	2x3=6	3x3=9
1x4=4	2x4=8	3x4=12	4x4=16
1x5=5	2x5=10	3x5=15	4x5=20	5x5=25
1x6=6	2x6=12	3x6=18	4x6=24	5x6=30	6x6=36
1x7=7	2x7=14	3x7=21	4x7=28	5x7=35	6x7=42	7x7=49
1x8=8	2x8=16	3x8=24	4x8=32	5x8=40	6x8=48	7x8=56	8x8=64
1x9=9	2x9=18	3x9=27	4x9=36	5x9=45	6x9=54	7x9=63	8x9=72	9x9=81
```

### 【提示】
外层 $i=1..9$，内层 $j=1..i$，输出 `j x i = j*i`。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            cout << j << "x" << i << "=" << j * i;
            if (j < i) cout << '\t';
        }
        cout << '\n';
    }
    return 0;
}
```

## 第 27 题 · 等腰三角形星号

### 【题目描述】
输入正整数 $n$，打印 $n$ 行等腰三角形。第 $i$ 行先输出 $n-i$ 个空格，再输出 $2i-1$ 个 `*`。

### 【输入描述】
一行，一个正整数 $n$（$1 \le n \le 30$）。

### 【输出描述】
共 $n$ 行图案。

### 【输入样例】
```
3
```

### 【输出样例】
```
  *
 ***
*****
```

### 【提示】
先打空格再打星号；行末一般不要求输出多余空格。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        // 先输出空格
        for (int s = 0; s < n - i; s++) {
            cout << ' ';
        }
        // 再输出奇数个星号
        for (int j = 0; j < 2 * i - 1; j++) {
            cout << '*';
        }
        cout << '\n';
    }
    return 0;
}
```

## 第 28 题 · 1 到 n 的位数总和

### 【题目描述】
输入正整数 $n$，统计把 $1,2,\ldots,n$ 全部写出来时一共有多少位数字。  
例如 $n=12$ 时，$1\sim9$ 共 $9$ 位，$10,11,12$ 共 $6$ 位，总和为 $15$。

### 【输入描述】
一行，一个正整数 $n$（$1 \le n \le 10^5$）。

### 【输出描述】
一行，输出位数总和。

### 【输入样例】
```
12
```

### 【输出样例】
```
15
```

### 【提示】
对每个数不断除以 $10$ 计数位数；注意 $n=1$ 时答案为 $1$。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    long long digits = 0;
    for (int i = 1; i <= n; i++) {
        int x = i;
        // 拆位统计位数
        do {
            digits++;
            x /= 10;
        } while (x > 0);
    }
    cout << digits << '\n';
    return 0;
}
```

## 第 29 题 · 输出 1 到 n 的平方

### 【题目描述】
输入正整数 $n$，依次输出 $1^2,2^2,\ldots,n^2$，相邻数字用空格隔开。

### 【输入描述】
一行，一个正整数 $n$（$1 \le n \le 1000$）。

### 【输出描述】
一行，输出各数的平方。

### 【输入样例】
```
5
```

### 【输出样例】
```
1 4 9 16 25
```

### 【提示】
注意 $n$ 较大时平方可能超过 `int`，可用 `long long`。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << ' ';
        cout << 1LL * i * i;
    }
    cout << '\n';
    return 0;
}
```

## 第 1 题 · 两数之和

### 【题目描述】
输入两个整数 $a$ 和 $b$，输出它们的和。

### 【输入描述】
一行，包含两个整数 $a$ 和 $b$（$-10^9 \le a,b \le 10^9$）。

### 【输出描述】
一行，输出 $a+b$ 的结果。

### 【输入样例】
```
3 5
```

### 【输出样例】
```
8
```

### 【提示】
注意 $a$、$b$ 可能很大，求和时建议使用 `long long`，避免溢出。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long a, b;
    cin >> a >> b;
    // 输出两数之和
    cout << a + b << '\n';
    return 0;
}
```

## 第 6 题 · 奇偶判断

### 【题目描述】
输入一个整数 $n$，判断它是奇数还是偶数。若为奇数输出 `odd`，若为偶数输出 `even`。

### 【输入描述】
一行，一个整数 $n$（$-10^9 \le n \le 10^9$）。

### 【输出描述】
一行，输出 `odd` 或 `even`。

### 【输入样例】
```
7
```

### 【输出样例】
```
odd
```

### 【提示】
可用 `n % 2 == 0` 判断偶数。注意负数：例如 `-3 % 2` 在 C++ 中为 `-1`，不等于 `0`，因此仍判断为奇数。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n;
    cin >> n;
    // 能被 2 整除则为偶数
    if (n % 2 == 0) {
        cout << "even\n";
    } else {
        cout << "odd\n";
    }
    return 0;
}
```

## 第 7 题 · 是否及格

### 【题目描述】
输入一个分数，判断是否及格。分数大于等于 $60$ 输出 `pass`，否则输出 `fail`。

### 【输入描述】
一行，一个整数 $score$（$0 \le score \le 100$）。

### 【输出描述】
一行，输出 `pass` 或 `fail`。

### 【输入样例】
```
60
```

### 【输出样例】
```
pass
```

### 【提示】
边界：输入 `59` 应输出 `fail`；输入 `0` 应输出 `fail`；输入 `100` 应输出 `pass`。

### 【C++参考代码】
```cpp
#include <iostream>

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int score;
    cin >> score;
    // 60 分及以上为及格
    if (score >= 60) {
        cout << "pass\n";
    } else {
        cout << "fail\n";
    }
    return 0;
}
```

## 第 8 题 · 三个数的最大值

### 【题目描述】
输入三个整数，输出其中的最大值。

### 【输入描述】
一行，包含三个整数 $a$、$b$、$c$（$-10^9 \le a,b,c \le 10^9$）。

### 【输出描述】
一行，输出三个数中的最大值。

### 【输入样例】
```
3 9 5
```

### 【输出样例】
```
9
```

### 【提示】
可用变量记录当前最大值，再依次与其余两个数比较。三个数都相等时，输出该数即可。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long a, b, c;
    cin >> a >> b >> c;

    // 先假设 a 最大，再和 b、c 比较
    long long mx = a;
    if (b > mx) mx = b;
    if (c > mx) mx = c;

    cout << mx << '\n';
    return 0;
}
```

## 第 10 题 · 闰年判断

### 【题目描述】
输入一个年份，判断它是否为闰年。  
闰年规则：能被 $4$ 整除且不能被 $100$ 整除，或者能被 $400$ 整除。  
若是闰年输出 `yes`，否则输出 `no`。

### 【输入描述】
一行，一个整数 $year$（$1 \le year \le 9999$）。

### 【输出描述】
一行，输出 `yes` 或 `no`。

### 【输入样例】
```
2000
```

### 【输出样例】
```
yes
```

### 【提示】
- `2000`：能被 $400$ 整除，是闰年  
- `1900`：能被 $100$ 整除但不能被 $400$ 整除，不是闰年  
- `2024`：能被 $4$ 整除且不能被 $100$ 整除，是闰年  

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int year;
    cin >> year;

    // 闰年：能被 400 整除，或能被 4 整除但不能被 100 整除
    bool leap = (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);

    if (leap) {
        cout << "yes\n";
    } else {
        cout << "no\n";
    }
    return 0;
}
```

## 第 1 题 · 完全背包方案数

### 【题目描述】
有 $n$ 种物品，第 $i$ 种重量为 $w_i$，每种无限。背包容量为 $V$，求恰好装满的方案数（顺序不同算同一种组合）。

### 【输入描述】
第一行两个整数 $n,V$（$1 \le n \le 100$，$1 \le V \le 1000$）。
第二行 $n$ 个正整数重量。

### 【输出描述】
一行，输出方案数。

### 【输入样例】
```
3 5
1 2 3
```

### 【输出样例】
```
5
```

### 【提示】
完全背包计数：正序更新。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, V;
    cin >> n >> V;
    vector<int> w(n);
    for (int i = 0; i < n; i++) cin >> w[i];
    vector<long long> dp(V + 1, 0);
    dp[0] = 1;
    for (int i = 0; i < n; i++) {
        for (int j = w[i]; j <= V; j++) {
            dp[j] += dp[j - w[i]];
        }
    }
    cout << dp[V] << '\n';
    return 0;
}
```

## 第 2 题 · Dijkstra 最短路

### 【题目描述】
给定 $n$ 个点 $m$ 条有向边（边权非负），求从源点 $s$ 到每个点的最短路。不可达输出 $-1$。

### 【输入描述】
第一行三个整数 $n,m,s$（$1 \le n \le 10^5$，$1 \le m \le 2\times 10^5$）。
接下来 $m$ 行：u v w。

### 【输出描述】
一行，$n$ 个整数，表示 $1..n$ 的最短路。

### 【输入样例】
```
4 4 1
1 2 1
1 3 4
2 3 2
3 4 1
```

### 【输出样例】
```
0 1 3 4
```

### 【提示】
堆优化 Dijkstra。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;

const int N = 100010;
vector<pair<int, int> > e[N];
long long dist[N];
bool vis[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m, s;
    cin >> n >> m >> s;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        e[u].push_back(make_pair(v, w));
    }
    for (int i = 1; i <= n; i++) dist[i] = 1e18;
    dist[s] = 0;
    priority_queue<pair<long long, int>, vector<pair<long long, int> >, greater<pair<long long, int> > > pq;
    pq.push(make_pair(0, s));
    while (!pq.empty()) {
        int u = pq.top().second;
        pq.pop();
        if (vis[u]) continue;
        vis[u] = true;
        for (int i = 0; i < (int)e[u].size(); i++) {
            int v = e[u][i].first, w = e[u][i].second;
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push(make_pair(dist[v], v));
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << ' ';
        cout << (dist[i] >= 1e18 ? -1 : dist[i]);
    }
    cout << '\n';
    return 0;
}
```

## 第 3 题 · Kruskal 最小生成树

### 【题目描述】
给定无向连通图，求最小生成树边权之和；若不连通输出 $-1$。

### 【输入描述】
第一行两个整数 $n,m$。
接下来 $m$ 行：u v w。

### 【输出描述】
一行，输出 MST 权值和或 $-1$。

### 【输入样例】
```
4 5
1 2 1
1 3 4
2 3 2
2 4 5
3 4 3
```

### 【输出样例】
```
6
```

### 【提示】
边排序 + 并查集。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Edge {
    int u, v, w;
};
vector<int> fa;
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m;
    cin >> n >> m;
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) cin >> edges[i].u >> edges[i].v >> edges[i].w;
    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    fa.resize(n + 1);
    for (int i = 1; i <= n; i++) fa[i] = i;
    long long sum = 0;
    int cnt = 0;
    for (int i = 0; i < m; i++) {
        int fu = find(edges[i].u), fv = find(edges[i].v);
        if (fu != fv) {
            fa[fu] = fv;
            sum += edges[i].w;
            cnt++;
        }
    }
    cout << (cnt == n - 1 ? sum : -1) << '\n';
    return 0;
}
```

## 第 4 题 · Prim 最小生成树

### 【题目描述】
用 Prim 算法求无向连通图最小生成树权值和；不连通输出 $-1$。

### 【输入描述】
第一行两个整数 $n,m$。
接下来 $m$ 行：u v w。

### 【输出描述】
一行，输出权值和或 $-1$。

### 【输入样例】
```
4 5
1 2 1
1 3 4
2 3 2
2 4 5
3 4 3
```

### 【输出样例】
```
6
```

### 【提示】
堆优化 Prim。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

const int N = 5010;
vector<pair<int, int> > e[N];
long long dist[N];
bool vis[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        e[u].push_back(make_pair(v, w));
        e[v].push_back(make_pair(u, w));
    }
    for (int i = 1; i <= n; i++) dist[i] = 1e18;
    dist[1] = 0;
    priority_queue<pair<long long, int>, vector<pair<long long, int> >, greater<pair<long long, int> > > pq;
    pq.push(make_pair(0, 1));
    long long sum = 0;
    int cnt = 0;
    while (!pq.empty()) {
        int u = pq.top().second;
        long long d = pq.top().first;
        pq.pop();
        if (vis[u]) continue;
        vis[u] = true;
        sum += d;
        cnt++;
        for (int i = 0; i < (int)e[u].size(); i++) {
            int v = e[u][i].first, w = e[u][i].second;
            if (!vis[v] && w < dist[v]) {
                dist[v] = w;
                pq.push(make_pair(w, v));
            }
        }
    }
    cout << (cnt == n ? sum : -1) << '\n';
    return 0;
}
```

## 第 5 题 · 拓扑排序

### 【题目描述】
给定有向图，若存在拓扑序则输出任意一个；若有环输出 `has cycle`。

### 【输入描述】
第一行两个整数 $n,m$。
接下来 $m$ 行有向边 u->v。

### 【输出描述】
一行拓扑序，或 `has cycle`。

### 【输入样例】
```
4 3
1 2
2 3
1 4
```

### 【输出样例】
```
1 2 4 3
```

### 【提示】
样例拓扑序不唯一。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m;
    cin >> n >> m;
    vector<vector<int> > e(n + 1);
    vector<int> indeg(n + 1, 0);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        e[u].push_back(v);
        indeg[v]++;
    }
    queue<int> q;
    for (int i = 1; i <= n; i++) if (indeg[i] == 0) q.push(i);
    vector<int> ans;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ans.push_back(u);
        for (int i = 0; i < (int)e[u].size(); i++) {
            int v = e[u][i];
            if (--indeg[v] == 0) q.push(v);
        }
    }
    if ((int)ans.size() != n) {
        cout << "has cycle\n";
        return 0;
    }
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
```

## 第 6 题 · KMP 字符串匹配

### 【题目描述】
在文本串 $s$ 中查找模式串 $p$ 的所有出现位置（从 $0$ 开始），每个位置占一行。

### 【输入描述】
第一行字符串 $s$。
第二行字符串 $p$。

### 【输出描述】
若干行匹配位置；若无匹配则不输出。

### 【输入样例】
```
abababa
aba
```

### 【输出样例】
```
0
2
4
```

### 【提示】
先求 next 数组再匹配。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

vector<int> getNext(const string& p) {
    int m = p.size();
    vector<int> nxt(m, 0);
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && p[i] != p[j]) j = nxt[j - 1];
        if (p[i] == p[j]) j++;
        nxt[i] = j;
    }
    return nxt;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    string s, p;
    cin >> s >> p;
    vector<int> nxt = getNext(p);
    int n = s.size(), m = p.size();
    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && s[i] != p[j]) j = nxt[j - 1];
        if (s[i] == p[j]) j++;
        if (j == m) {
            cout << i - m + 1 << '\n';
            j = nxt[j - 1];
        }
    }
    return 0;
}
```

## 第 7 题 · 线段树单点修改区间和

### 【题目描述】
维护长度为 $n$ 的数组：
- 操作 1：把位置 $x$ 修改为 $y$
- 操作 2：查询区间 $[l,r]$ 的和

### 【输入描述】
第一行两个整数 $n,q$。
第二行 $n$ 个整数。
接下来 $q$ 行操作。

### 【输出描述】
对每个查询输出一行。

### 【输入样例】
```
5 3
1 2 3 4 5
2 1 5
1 3 10
2 2 4
```

### 【输出样例】
```
15
16
```

### 【提示】
线段树基础。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<long long> tr;

void update(int p, long long v, int i, int l, int r) {
    if (l == r) { tr[i] = v; return; }
    int mid = (l + r) / 2;
    if (p <= mid) update(p, v, i * 2, l, mid);
    else update(p, v, i * 2 + 1, mid + 1, r);
    tr[i] = tr[i * 2] + tr[i * 2 + 1];
}

long long query(int ql, int qr, int i, int l, int r) {
    if (ql <= l && r <= qr) return tr[i];
    int mid = (l + r) / 2;
    long long s = 0;
    if (ql <= mid) s += query(ql, qr, i * 2, l, mid);
    if (qr > mid) s += query(ql, qr, i * 2 + 1, mid + 1, r);
    return s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int q;
    cin >> n >> q;
    tr.assign(4 * n + 5, 0);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        update(i, x, 1, 1, n);
    }
    while (q--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) update(x, y, 1, 1, n);
        else cout << query(x, y, 1, 1, n) << '\n';
    }
    return 0;
}
```

## 第 8 题 · 线段树区间加区间和

### 【题目描述】
维护数组：
- 操作 1：区间 $[l,r]$ 同时加 $v$
- 操作 2：查询区间 $[l,r]$ 的和

### 【输入描述】
第一行两个整数 $n,q$。
第二行 $n$ 个整数。
接下来 $q$ 行：
`1 l r v` 或 `2 l r`

### 【输出描述】
对每个查询输出一行。

### 【输入样例】
```
5 3
1 2 3 4 5
1 2 4 1
2 1 5
2 2 3
```

### 【输出样例】
```
18
7
```

### 【提示】
懒标记线段树。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<long long> tr, lazy;

void push(int i, int l, int r) {
    if (!lazy[i] || l == r) return;
    int mid = (l + r) / 2;
    tr[i * 2] += lazy[i] * (mid - l + 1);
    lazy[i * 2] += lazy[i];
    tr[i * 2 + 1] += lazy[i] * (r - mid);
    lazy[i * 2 + 1] += lazy[i];
    lazy[i] = 0;
}

void update(int ql, int qr, long long v, int i, int l, int r) {
    if (ql <= l && r <= qr) {
        tr[i] += v * (r - l + 1);
        lazy[i] += v;
        return;
    }
    push(i, l, r);
    int mid = (l + r) / 2;
    if (ql <= mid) update(ql, qr, v, i * 2, l, mid);
    if (qr > mid) update(ql, qr, v, i * 2 + 1, mid + 1, r);
    tr[i] = tr[i * 2] + tr[i * 2 + 1];
}

long long query(int ql, int qr, int i, int l, int r) {
    if (ql <= l && r <= qr) return tr[i];
    push(i, l, r);
    int mid = (l + r) / 2;
    long long s = 0;
    if (ql <= mid) s += query(ql, qr, i * 2, l, mid);
    if (qr > mid) s += query(ql, qr, i * 2 + 1, mid + 1, r);
    return s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int q;
    cin >> n >> q;
    tr.assign(4 * n + 5, 0);
    lazy.assign(4 * n + 5, 0);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        update(i, i, x, 1, 1, n);
    }
    while (q--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 1) {
            long long v;
            cin >> v;
            update(l, r, v, 1, 1, n);
        } else {
            cout << query(l, r, 1, 1, n) << '\n';
        }
    }
    return 0;
}
```

## 第 9 题 · 数位 DP：不含数字 4

### 【题目描述】
统计区间 $[L,R]$ 中十进制表示不含数字 $4$ 的整数个数。

### 【输入描述】
一行两个整数 $L,R$（$0 \le L \le R \le 10^{18}$）。

### 【输出描述】
一行，输出个数。

### 【输入样例】
```
1 20
```

### 【输出样例】
```
18
```

### 【提示】
因为 $4$ 和 $14$ 不含（这里 1..20 中含 4 的是 4,14，共 2 个，故 20-2=18）。含前导情况用数位 DP 处理。

### 【C++参考代码】
```cpp
#include <iostream>
#include <string>
#include <cstring>
using namespace std;

string s;
long long dp[20][2];

long long dfs(int pos, bool limit, bool started) {
    if (pos == (int)s.size()) return started ? 1 : 1; // 含 0
    if (!limit && started && dp[pos][started] != -1) return dp[pos][started];
    // 简化：统一记忆化键
    int up = limit ? s[pos] - '0' : 9;
    long long ans = 0;
    for (int d = 0; d <= up; d++) {
        if (d == 4) continue;
        ans += dfs(pos + 1, limit && d == up, started || d > 0);
    }
    // 对未开始的状态也返回（全 0）
    if (!started) {
        // 上面循环已包含继续不开始的情况（d=0）
    }
    if (!limit && started) dp[pos][started] = ans;
    return ans;
}

long long solve(long long n) {
    if (n < 0) return 0;
    s = to_string(n);
    memset(dp, -1, sizeof(dp));
    return dfs(0, true, false);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    long long L, R;
    cin >> L >> R;
    cout << solve(R) - solve(L - 1) << '\n';
    return 0;
}
```

## 第 10 题 · 状压 DP：TSP

### 【题目描述】
给出 $n$ 个城市两两距离，求从城市 $0$ 出发经过所有城市恰好一次再回到 $0$ 的最短路径（小规模 TSP）。

### 【输入描述】
第一行一个整数 $n$（$2 \le n \le 16$）。
接下来 $n$ 行，每行 $n$ 个整数表示距离矩阵。

### 【输出描述】
一行，输出最短回路长度。

### 【输入样例】
```
4
0 1 2 3
1 0 4 5
2 4 0 6
3 5 6 0
```

### 【输出样例】
```
14
```

### 【提示】
状态压缩 DP：`dp[s][u]`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <cstring>
using namespace std;

int n;
int dist[20][20];
long long dp[1 << 16][16];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> dist[i][j];
    memset(dp, 0x3f, sizeof(dp));
    dp[1][0] = 0;
    for (int s = 1; s < (1 << n); s++) {
        for (int u = 0; u < n; u++) {
            if (!(s >> u & 1)) continue;
            for (int v = 0; v < n; v++) {
                if (s >> v & 1) continue;
                int ns = s | (1 << v);
                dp[ns][v] = min(dp[ns][v], dp[s][u] + dist[u][v]);
            }
        }
    }
    long long ans = 1e18;
    for (int i = 1; i < n; i++) {
        ans = min(ans, dp[(1 << n) - 1][i] + dist[i][0]);
    }
    cout << ans << '\n';
    return 0;
}
```

## 第 21 题 · 字符串长度

### 【题目描述】
输入一行字符串（可能包含空格），输出它的长度。

### 【输入描述】
一行字符串（长度不超过 $1000$）。

### 【输出描述】
一行，输出字符串长度。

### 【输入样例】
```
hello world
```

### 【输出样例】
```
11
```

### 【提示】
使用 `getline` 读入整行。

### 【C++参考代码】
```cpp

#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;
    getline(cin, s);
    cout << s.size() << '\n';

    return 0;
}
```

## 第 22 题 · 倒序输出字符串

### 【题目描述】
输入一行字符串，倒序输出。

### 【输入描述】
一行字符串（长度不超过 $1000$，不含换行）。

### 【输出描述】
一行，输出倒序后的字符串。

### 【输入样例】
```
abcd
```

### 【输出样例】
```
dcba
```

### 【提示】
从后往前遍历输出即可。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;
    getline(cin, s);
    for (int i = (int)s.size() - 1; i >= 0; i--) cout << s[i];
    cout << '\n';

    return 0;
}
```

## 第 23 题 · 回文字符串判断

### 【题目描述】
输入一个字符串（不含空格），判断是否为回文。是则输出 `yes`，否则输出 `no`。

### 【输入描述】
一行，一个字符串（长度不超过 $1000$）。

### 【输出描述】
一行，输出 `yes` 或 `no`。

### 【输入样例】
```
abba
```

### 【输出样例】
```
yes
```

### 【提示】
左右指针向中间移动比较。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;
    cin >> s;
    bool ok = true;
    for (int i = 0, j = (int)s.size() - 1; i < j; i++, j--) {
        if (s[i] != s[j]) { ok = false; break; }
    }
    cout << (ok ? "yes" : "no") << '\n';

    return 0;
}
```

## 第 30 题 · 查找子串位置（模拟）

### 【题目描述】
输入主串 $s$ 和模式串 $t$，输出 $t$ 在 $s$ 中第一次出现的起始下标（从 $0$ 开始）。若不存在输出 $-1$。不允许使用 `string::find`。

### 【输入描述】
第一行字符串 $s$。
第二行字符串 $t$。
（长度均不超过 $1000$）

### 【输出描述】
一行，输出下标或 $-1$。

### 【输入样例】
```
abcdef
cd
```

### 【输出样例】
```
2
```

### 【提示】
枚举起始位置暴力匹配。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s, t;
    getline(cin, s);
    getline(cin, t);
    int ans = -1;
    if (t.size() <= s.size()) {
        for (int i = 0; i + (int)t.size() <= (int)s.size(); i++) {
            bool ok = true;
            for (int j = 0; j < (int)t.size(); j++) {
                if (s[i + j] != t[j]) { ok = false; break; }
            }
            if (ok) { ans = i; break; }
        }
    }
    cout << ans << '\n';

    return 0;
}
```

## 第 31 题 · 水仙花数

### 【题目描述】
输出 $100$ 到 $999$ 中所有水仙花数（各位数字立方和等于该数本身），每个数占一行。

### 【输入描述】
无输入。

### 【输出描述】
若干行，从小到大输出水仙花数。

### 【输入样例】
```
（无）
```

### 【输出样例】
```
153
370
371
407
```

### 【提示】
枚举三位数并拆位即可。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    for (int n = 100; n <= 999; n++) {
        int a = n / 100, b = n / 10 % 10, c = n % 10;
        if (a * a * a + b * b * b + c * c * c == n) {
            cout << n << '\n';
        }
    }

    return 0;
}
```

## 第 32 题 · 百钱买百鸡

### 【题目描述】
鸡翁一值钱五，鸡母一值钱三，鸡雏三值钱一。百钱买百鸡，输出所有方案。每行输出三个整数：鸡翁、鸡母、鸡雏数量。

### 【输入描述】
无输入。

### 【输出描述】
若干行，每行一种方案。

### 【输入样例】
```
（无）
```

### 【输出样例】
```
0 25 75
4 18 78
8 11 81
12 4 84
```

### 【提示】
三重循环枚举，注意鸡雏数是 $3$ 的倍数。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    // x 翁 y 母 z 雏，x+y+z=100，5x+3y+z/3=100
    for (int x = 0; x <= 20; x++) {
        for (int y = 0; y <= 33; y++) {
            int z = 100 - x - y;
            if (z >= 0 && z % 3 == 0 && 5 * x + 3 * y + z / 3 == 100) {
                cout << x << ' ' << y << ' ' << z << '\n';
            }
        }
    }

    return 0;
}
```

## 第 33 题 · 秒转时分秒

### 【题目描述】
输入一个非负整数秒数，转换成 `hh:mm:ss` 格式输出（不足两位补零）。小时可以超过 $24$。

### 【输入描述】
一行，一个非负整数 $s$（$0 \le s \le 10^{9}$）。

### 【输出描述】
一行，输出 `hh:mm:ss`。

### 【输入样例】
```
3661
```

### 【输出样例】
```
01:01:01
```

### 【提示】
边界：输入 `0` 输出 `00:00:00`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long s;
    cin >> s;
    long long h = s / 3600;
    long long m = (s % 3600) / 60;
    long long sec = s % 60;
    cout << setfill('0') << setw(2) << h << ':'
         << setw(2) << m << ':' << setw(2) << sec << '\n';

    return 0;
}
```

## 第 34 题 · 一年中的第几天（忽略闰年）

### 【题目描述】
输入年、月、日，输出这一天是当年的第几天。不考虑闰年，二月按 $28$ 天计算。

### 【输入描述】
一行，三个整数 $y,m,d$（$1 \le y \le 9999$，$1 \le m \le 12$，日期合法）。

### 【输出描述】
一行，输出天数。

### 【输入样例】
```
2024 3 1
```

### 【输出样例】
```
60
```

### 【提示】
把前 $m-1$ 个月天数累加再加上 $d$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int y, m, d;
    cin >> y >> m >> d;
    int days[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
    int ans = d;
    for (int i = 1; i < m; i++) ans += days[i];
    cout << ans << '\n';

    return 0;
}
```

## 第 35 题 · 十进制转二进制

### 【题目描述】
输入一个非负整数，输出它的二进制表示（不使用库函数直接转换）。

### 【输入描述】
一行，一个非负整数 $n$（$0 \le n \le 10^{9}$）。

### 【输出描述】
一行，输出二进制字符串（不含前导零，除非 $n=0$）。

### 【输入样例】
```
10
```

### 【输出样例】
```
1010
```

### 【提示】
$n=0$ 输出 `0`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n;
    cin >> n;
    if (n == 0) {
        cout << "0\n";
        return 0;
    }
    string s;
    while (n > 0) {
        s = char('0' + (n % 2)) + s;
        n /= 2;
    }
    cout << s << '\n';

    return 0;
}
```

## 第 36 题 · 二进制字符串相加

### 【题目描述】
输入两个二进制字符串，输出它们的和（仍为二进制字符串，不含前导零，除非结果为 $0$）。

### 【输入描述】
一行，两个二进制字符串 $a,b$（长度不超过 $1000$，仅含 `0/1`）。

### 【输出描述】
一行，输出二进制和。

### 【输入样例】
```
1010 1011
```

### 【输出样例】
```
10101
```

### 【提示】
从低位到高位模拟加法进位。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string a, b;
    cin >> a >> b;
    string r;
    int i = (int)a.size() - 1, j = (int)b.size() - 1, c = 0;
    while (i >= 0 || j >= 0 || c) {
        int sum = c;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        r = char('0' + sum % 2) + r;
        c = sum / 2;
    }
    // 去掉前导零
    int p = 0;
    while (p + 1 < (int)r.size() && r[p] == '0') p++;
    cout << r.substr(p) << '\n';

    return 0;
}
```

## 第 37 题 · 模拟投票

### 【题目描述】
输入 $n$ 张选票（候选人编号），统计每个候选人的得票数，按编号从小到大输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数，表示候选人编号（$1 \le$ 编号 $\le 1000$）。

### 【输出描述】
若干行，每行：编号 票数。

### 【输入样例】
```
6
1 2 1 3 2 1
```

### 【输出样例】
```
1 3
2 2
3 1
```

### 【提示】
可用数组计数或 `map`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    map<int, int> cnt;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        cnt[x]++;
    }
    for (map<int, int>::iterator it = cnt.begin(); it != cnt.end(); ++it) {
        cout << it->first << ' ' << it->second << '\n';
    }

    return 0;
}
```

## 第 38 题 · 最高最低平均分

### 【题目描述】
输入 $n$ 个学生分数，输出最高分、最低分和平均分（平均分保留两位小数）。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数分数（$0 \le$ 分数 $\le 100$）。

### 【输出描述】
一行，输出最高分、最低分、平均分，空格隔开。

### 【输入样例】
```
4
80 90 70 100
```

### 【输出样例】
```
100 70 85.00
```

### 【提示】
$n=1$ 时三者分别为该分数、该分数、该分数。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    int mx, mn;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (i == 0) mx = mn = x;
        else {
            if (x > mx) mx = x;
            if (x < mn) mn = x;
        }
        sum += x;
    }
    cout << mx << ' ' << mn << ' ' << fixed << setprecision(2) << (double)sum / n << '\n';

    return 0;
}
```

```
67

73

```

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
```

## 第 40 题 · FizzBuzz

### 【题目描述】
输入正整数 $n$，对 $1$ 到 $n$：能被 $3$ 整除输出 `Fizz`，能被 $5$ 整除输出 `Buzz`，同时被 $3$ 和 $5$ 整除输出 `FizzBuzz`，否则输出数字本身。每个结果占一行。

### 【输入描述】
一行，一个正整数 $n$（$1 \le n \le 1000$）。

### 【输出描述】
共 $n$ 行。

### 【输入样例】
```
15
```

### 【输出样例】
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

### 【提示】
先判断 $15$ 的倍数，再判断 $3$ 或 $5$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
#include <cctype>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i % 15 == 0) cout << "FizzBuzz\n";
        else if (i % 3 == 0) cout << "Fizz\n";
        else if (i % 5 == 0) cout << "Buzz\n";
        else cout << i << '\n';
    }

    return 0;
}
```

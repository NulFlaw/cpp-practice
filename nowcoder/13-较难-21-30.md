## 第 21 题 · 01 背包

### 【题目描述】
有 $n$ 件物品，第 $i$ 件重量 $w_i$、价值 $v_i$。背包容量为 $V$，每件最多选一次，求最大价值。

### 【输入描述】
第一行两个整数 $n,V$（$1 \le n \le 100$，$1 \le V \le 1000$）。
接下来 $n$ 行，每行两个整数 $w_i,v_i$。

### 【输出描述】
一行，输出最大价值。

### 【输入样例】
```
3 5
2 3
3 4
4 5
```

### 【输出样例】
```
7
```

### 【提示】
经典一维 DP：逆序更新。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, V;
    cin >> n >> V;
    vector<int> dp(V + 1, 0);
    for (int i = 0; i < n; i++) {
        int w, v;
        cin >> w >> v;
        for (int j = V; j >= w; j--) {
            dp[j] = max(dp[j], dp[j - w] + v);
        }
    }
    cout << dp[V] << '\n';

    return 0;
}
```

## 第 22 题 · 最长上升子序列 LIS

### 【题目描述】
给定长度为 $n$ 的序列，求最长严格上升子序列长度。$O(n^2)$ 做法即可。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，输出 LIS 长度。

### 【输入样例】
```
6
1 4 2 3 5 2
```

### 【输出样例】
```
4
```

### 【提示】
例如 $1,2,3,5$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n), dp(n, 1);
    for (int i = 0; i < n; i++) cin >> a[i];
    int ans = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        }
        ans = max(ans, dp[i]);
    }
    cout << ans << '\n';

    return 0;
}
```

## 第 23 题 · 最长公共子序列 LCS

### 【题目描述】
给定两个字符串，求最长公共子序列长度。

### 【输入描述】
两行，两个字符串（长度不超过 $1000$，仅小写字母）。

### 【输出描述】
一行，输出 LCS 长度。

### 【输入样例】
```
abcde
ace
```

### 【输出样例】
```
3
```

### 【提示】
二维 DP。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string a, b;
    cin >> a >> b;
    int n = a.size(), m = b.size();
    vector<vector<int> > dp(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (a[i - 1] == b[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    cout << dp[n][m] << '\n';

    return 0;
}
```

## 第 24 题 · 爬楼梯

### 【题目描述】
一次可走 $1$ 或 $2$ 阶，求走到第 $n$ 阶的方案数。

### 【输入描述】
一行，一个整数 $n$（$1 \le n \le 40$）。

### 【输出描述】
一行，输出方案数。

### 【输入样例】
```
5
```

### 【输出样例】
```
8
```

### 【提示】
递推：$f(n)=f(n-1)+f(n-2)$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

        cout << n << '\n';

        long long c = a + b;
        a = b;
```

## 第 25 题 · 双指针两数之和

### 【题目描述】
给定升序数组，找两个下标 $i<j$ 使得 $a[i]+a[j]=target$。输出任意一组下标（$0$ 开始）；若不存在输出 `-1 -1`。

### 【输入描述】
第一行两个整数 $n,target$。
第二行 $n$ 个升序整数。

### 【输出描述】
一行，两个下标或 `-1 -1`。

### 【输入样例】
```
4 9
2 3 6 7
```

### 【输出样例】
```
0 3
```

### 【提示】
左右指针相向移动。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int l = 0, r = n - 1;
    while (l < r) {
        int sum = a[l] + a[r];
        if (sum == target) {
            cout << l << ' ' << r << '\n';
            return 0;
        } else if (sum < target) l++;
        else r--;
    }
    cout << "-1 -1\n";

    return 0;
}
```

## 第 26 题 · 滑动窗口最长子数组

### 【题目描述】
给定数组与上限 $S$，求元素和不超过 $S$ 的最长连续子数组长度。若不存在输出 $0$。

### 【输入描述】
第一行两个整数 $n,S$（$1 \le n \le 10^5$，$0 \le S \le 10^{14}$）。
第二行 $n$ 个非负整数。

### 【输出描述】
一行，输出最长长度。

### 【输入样例】
```
5 7
2 3 1 2 4
```

### 【输出样例】
```
3
```

### 【提示】
例如 $3,1,2$ 和为 $6$。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    long long S;
    cin >> n >> S;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int l = 0, ans = 0;
    long long sum = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (l <= r && sum > S) {
            sum -= a[l];
            l++;
        }
        ans = max(ans, r - l + 1);
    }
    cout << ans << '\n';

    return 0;
}
```

## 第 27 题 · 邻接表存图

### 【题目描述】
给定 $n$ 个点 $m$ 条无向边，用邻接表存储并输出每个点的邻居（按输入加入顺序）。

### 【输入描述】
第一行两个整数 $n,m$（$1 \le n \le 1000$，$0 \le m \le 5000$）。
接下来 $m$ 行，每行两个整数 $u,v$。

### 【输出描述】
输出 $n$ 行，第 $i$ 行格式：`i:` 后跟邻居列表。

### 【输入样例】
```
3 2
1 2
2 3
```

### 【输出样例】
```
1: 2
2: 1 3
3: 2
```

### 【提示】
无向边要加两次。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    cin >> n >> m;
    vector<vector<int> > adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    for (int i = 1; i <= n; i++) {
        cout << i << ':';
        for (int j = 0; j < (int)adj[i].size(); j++) {
            cout << ' ' << adj[i][j];
        }
        cout << '\n';
    }

    return 0;
}
```

## 第 28 题 · 二叉树三种遍历

### 【题目描述】
手动建立如下二叉树并输出前序、中序、后序遍历（每行一种，数字用空格隔开）：
```
    1
   / \
  2   3
```

### 【输入描述】
无输入。

### 【输出描述】
三行，分别为前序、中序、后序。

### 【输入样例】
```
（无）
```

### 【输出样例】
```
1 2 3
2 1 3
2 3 1
```

### 【提示】
递归遍历模板。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

struct Node {
    int val;
    Node *l, *r;
    Node(int v) : val(v), l(0), r(0) {}
};

void pre(Node* p) {
    if (!p) return;
    cout << p->val << ' ';
    pre(p->l);
    pre(p->r);
}
void inorder(Node* p) {
    if (!p) return;
    inorder(p->l);
    cout << p->val << ' ';
    inorder(p->r);
}
void post(Node* p) {
    if (!p) return;
    post(p->l);
    post(p->r);
    cout << p->val << ' ';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    Node* root = new Node(1);
    root->l = new Node(2);
    root->r = new Node(3);
    pre(root); cout << '\n';
    inorder(root); cout << '\n';
    post(root); cout << '\n';
    return 0;
}
```

## 第 29 题 · 并查集

### 【题目描述】
实现并查集。操作：
- `1 x y`：合并 $x,y$
- `2 x y`：查询是否连通，是输出 `yes`，否输出 `no`

### 【输入描述】
第一行两个整数 $n,q$（$1 \le n \le 10^5$，$1 \le q \le 10^5$）。
接下来 $q$ 行操作。

### 【输出描述】
对每个查询输出一行。

### 【输入样例】
```
5 5
1 1 2
1 2 3
2 1 3
2 1 4
1 4 5
```

### 【输出样例】
```
yes
no
```

### 【提示】
路径压缩。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> fa;
int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, q;
    cin >> n >> q;
    fa.resize(n + 1);
    for (int i = 1; i <= n; i++) fa[i] = i;
    while (q--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            fa[find(x)] = find(y);
        } else {
            cout << (find(x) == find(y) ? "yes" : "no") << '\n';
        }
    }
    return 0;
}
```

## 第 30 题 · 单调栈：右侧更大元素

### 【题目描述】
对数组每个位置，求它右侧第一个严格更大的元素；若不存在输出 $-1$。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 10^5$）。
第二行 $n$ 个整数。

### 【输出描述】
一行，$n$ 个答案。

### 【输入样例】
```
5
2 1 2 4 3
```

### 【输出样例】
```
4 2 4 -1 -1
```

### 【提示】
从左到右维护单调递减栈。

### 【C++参考代码】
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <cstring>
#include <queue>
#include <stack>
#include <map>
#include <set>
#include <sstream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<int> a(n), ans(n, -1);
    for (int i = 0; i < n; i++) cin >> a[i];
    stack<int> st; // 存下标
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = a[i];
            st.pop();
        }
        st.push(i);
    }
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';

    return 0;
}
```

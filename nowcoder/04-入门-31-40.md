## 第 31 题 · 读入 5 个数并输出

### 【题目描述】
输入 $5$ 个整数，存入数组后按原顺序全部输出。

### 【输入描述】
一行，包含 $5$ 个整数，相邻整数用空格隔开（每个数绝对值不超过 $10^9$）。

### 【输出描述】
一行，按原顺序输出这 $5$ 个数，相邻数字用空格隔开。

### 【输入样例】
```
1 2 3 4 5
```

### 【输出样例】
```
1 2 3 4 5
```

### 【提示】
固定长度数组 `int a[5]` 即可。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int a[5];
    for (int i = 0; i < 5; i++) {
        cin >> a[i];
    }
    for (int i = 0; i < 5; i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

## 第 32 题 · 读入 n 个数并输出

### 【题目描述】
先输入整数 $n$，再输入 $n$ 个整数，按原顺序全部输出。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。  
第二行 $n$ 个整数（每个数绝对值不超过 $10^9$）。

### 【输出描述】
一行，按原顺序输出这 $n$ 个数。

### 【输入样例】
```
3
10 20 30
```

### 【输出样例】
```
10 20 30
```

### 【提示】
可用静态数组 `int a[1000]`，也可用 `vector`（本档尽量用数组）。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    int a[1000];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

## 第 34 题 · 数组最大值

### 【题目描述】
输入 $n$ 和 $n$ 个整数，求数组中的最大值。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。  
第二行 $n$ 个整数（每个数绝对值不超过 $10^9$）。

### 【输出描述】
一行，输出最大值。

### 【输入样例】
```
5
3 1 9 2 7
```

### 【输出样例】
```
9
```

### 【提示】
先用第一个元素初始化最大值，再遍历比较。注意全为负数的情况。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    long long mx;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (i == 0 || x > mx) {
            mx = x;
        }
    }
    cout << mx << '\n';
    return 0;
}
```

## 第 36 题 · 数组平均值

### 【题目描述】
输入 $n$ 和 $n$ 个整数，求数组平均值，保留两位小数。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。  
第二行 $n$ 个整数（每个数绝对值不超过 $10^6$）。

### 【输出描述】
一行，输出平均值，保留两位小数。

### 【输入样例】
```
4
1 2 3 4
```

### 【输出样例】
```
2.50
```

### 【提示】
使用 `fixed` 与 `setprecision(2)`。注意总和用 `long long`。

### 【C++参考代码】
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
    }
    cout << fixed << setprecision(2) << (double)sum / n << '\n';
    return 0;
}
```

## 第 37 题 · 统计正数个数

### 【题目描述】
输入 $n$ 和 $n$ 个整数，统计其中正数的个数。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。  
第二行 $n$ 个整数。

### 【输出描述】
一行，输出正数个数。

### 【输入样例】
```
6
-1 0 2 3 -5 4
```

### 【输出样例】
```
3
```

### 【提示】
正数指大于 $0$ 的数，$0$ 不算正数。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x > 0) cnt++;
    }
    cout << cnt << '\n';
    return 0;
}
```

## 第 40 题 · 线性查找

### 【题目描述】
输入 $n$ 和 $n$ 个整数，再输入一个整数 $x$，判断 $x$ 是否出现在数组中。若存在输出 `yes`，否则输出 `no`。

### 【输入描述】
第一行一个整数 $n$（$1 \le n \le 1000$）。  
第二行 $n$ 个整数。  
第三行一个整数 $x$。

### 【输出描述】
一行，输出 `yes` 或 `no`。

### 【输入样例】
```
5
1 3 5 7 9
5
```

### 【输出样例】
```
yes
```

### 【提示】
从左到右扫描一次即可。若找不到则输出 `no`。

### 【C++参考代码】
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    int a[1000];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int x;
    cin >> x;

    bool found = false;
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            found = true;
            break;
        }
    }
    cout << (found ? "yes" : "no") << '\n';
    return 0;
}
```

# 03 · 智能指针与 RAII

## Q1. 什么是 RAII？为什么 C++ 特别强调它？

**答要点**

- **Resource Acquisition Is Initialization**：资源获取即初始化——在构造里获取，在析构里释放
- 作用域结束（包括异常栈展开）会自动调析构 → 不易泄漏
- 适用：内存、文件、锁、socket、句柄等
- Core Guidelines 核心实践；优先对象管理资源，而不是裸 `new`/`lock`/`fopen`

---

## Q2. `unique_ptr` / `shared_ptr` / `weak_ptr` 怎么选？

**答要点**

| 类型 | 语义 | 特点 |
|------|------|------|
| `unique_ptr` | 独占所有权 | 几乎零开销，不可拷贝只可移动；默认首选 |
| `shared_ptr` | 共享所有权 | 引用计数；有控制块开销 |
| `weak_ptr` | 观察、不延长寿命 | 打破循环引用；使用前 `lock()` |

原则：**能 unique 就不要 shared**。

---

## Q3. `shared_ptr` 的原理？控制块里有什么？

**答要点**

- 每个共享对象关联一块 **控制块**：强引用计数、弱引用计数、删除器、分配器等
- `shared_ptr` 拷贝增加强引用；强引用归零时销毁对象；弱引用也归零时销毁控制块
- `weak_ptr` 只影响弱计数，不阻止对象销毁

**追问**：`make_shared` 和 `shared_ptr(new T)` 的区别？

---

## Q4. 为什么推荐 `make_shared` / `make_unique`？

**答要点**

1. **异常安全**：`foo(shared_ptr<T>(new T), bar())` 中若 `bar` 抛异常可能泄漏；`make_*` 更安全
2. `make_shared` 常把**对象和控制块一次分配**，更好的局部性、少一次分配
3. 自定义删除器 / 不公开构造时，可能仍需 `shared_ptr(new T, deleter)`

---

## Q5. 什么是循环引用？如何解决？

**答要点**

- A 持有 B 的 `shared_ptr`，B 持有 A 的 `shared_ptr` → 计数永远不为 0 → 泄漏
- 典型：父子、图中双向边、观察者
- 解法：一侧改用 `weak_ptr`；或重新设计所有权（谁拥有谁）

---

## Q6. `enable_shared_from_this` 解决什么问题？

**答要点**

- 在成员函数里需要「指向 this 的 `shared_ptr`」时，不能直接 `shared_ptr<T>(this)`（会新建控制块 → 双重释放）
- 继承 `enable_shared_from_this<T>`，用 `shared_from_this()`
- 前提：对象必须已由某个 `shared_ptr` 管理；否则抛异常 / UB（视标准库）

---

## Q7. `shared_ptr` 线程安全吗？

**答要点**

- **控制块上的引用计数**是原子的，多线程拷贝/销毁 `shared_ptr` 管理同一对象通常安全
- **被管理对象本身的读写**不保证线程安全，仍需 mutex / 原子 / 不可变设计
- 多线程下**同一个 `shared_ptr` 实例**被并发读写（非 const）也不安全，应各线程持有自己的拷贝，或加锁保护该指针变量

---

## Q8. `unique_ptr` 能用于数组吗？自定义删除器怎么写？

**答要点**

- `unique_ptr<T[]>` 会用 `delete[]`
- 自定义删除器：函数对象 / 函数指针 / lambda，作为模板第二参数或 `shared_ptr` 构造参数
- 管理文件句柄、`malloc` 内存、C API 资源时很常见

---

## Q9. 智能指针和裸指针如何协作？

**答要点**

- 所有权用智能指针；非拥有观察可用裸指针 / 引用 / `weak_ptr` / `span`
- 不要从临时 `shared_ptr` 取出裸指针再长期保存
- 函数参数：不涉及所有权传递时优先 `T*` / `T&` / `span`，避免无意义的智能指针传参增加计数

---

## Q10. 手写一个简易 `shared_ptr` 要考虑哪些点？（常考设计题）

**答要点**

1. 控制块：强/弱计数（可用 `atomic`）
2. 拷贝构造/赋值增减计数；析构减计数并在归零时 delete
3. 移动语义：偷指针与控制块，源置空
4. 自赋值安全
5. 可选：`weak_ptr`、自定义删除器、`make_shared` 一体分配
6. 线程安全策略要说清楚（计数原子 ≠ 对象安全）

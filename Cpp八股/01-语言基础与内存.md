# 01 · 语言基础与内存

## Q1. 进程地址空间大致怎么划分？

**答要点**

- **代码段（text）**：机器指令，通常只读
- **只读数据（rodata）**：字符串字面量、`const` 全局等
- **数据段（data）**：已初始化的全局 / 静态变量
- **BSS**：未初始化或初始化为 0 的全局 / 静态变量（可执行文件里常不占实际空间）
- **堆（heap）**：动态分配，一般向高地址增长
- **栈（stack）**：局部变量、调用帧，一般向低地址增长
- 还有映射区（共享库、mmap 等）

**追问**：全局变量和静态局部变量分别放哪？静态局部变量有什么初始化特点？

## Q2. 栈和堆有什么区别？什么时候用哪个？

**答要点**

| | 栈 | 堆 |
|--|--|--|
| 分配 | 自动、极快 | `new`/`malloc`，有分配器开销 |
| 释放 | 离开作用域自动析构 | 需手动或智能指针 |
| 大小 | 通常较小（如默认数 MB 级） | 受系统内存限制，更灵活 |
| 典型用途 | 小对象、短生命周期 | 大对象、跨作用域共享、运行期才定大小 |

**追问**：大数组放栈上可能怎样？递归过深会怎样？

## Q3. `new`/`delete` 和 `malloc`/`free` 有什么区别？

**答要点**

1. `new`：分配 + 调用构造；`delete`：析构 + 释放
2. `malloc`：只按字节分配，不调构造/析构；返回 `void*`
3. `new` 失败默认抛 `std::bad_alloc`；`malloc` 失败返回 `nullptr`
4. 必须配对：`new`↔`delete`，`new[]`↔`delete[]`，`malloc`↔`free`；混用是未定义行为
5. `new` 可重载、可配合定位 `new`；C++ 里优先 RAII / 智能指针，少直接裸 `new`

**追问**：`delete` 和 `delete[]` 混用会怎样？定位 `new` 是什么？

## Q4. 什么是内存泄漏？悬空指针？野指针？

**答要点**

- **内存泄漏**：堆内存不再可达却未释放（或资源未归还）
- **悬空指针**：指向已释放对象的指针
- **野指针**：未初始化的指针

**预防**：RAII、智能指针、尽快置空、限制裸指针生命周期、AddressSanitizer / Valgrind。

---

## Q5. 什么是内存对齐？为什么要对齐？

**答要点**

- 编译器按类型自然对齐要求在结构体成员间插入 padding，使地址满足对齐
- 目的：硬件访问效率、部分架构强制对齐否则 trap
- `sizeof`、`alignof`、`#pragma pack` / `alignas` 可观察或调整
- 面试常考：手算结构体 `sizeof`（注意顺序影响 padding）

**示例思路**：`struct { char; int; }` 与 `struct { int; char; }` 的大小可能不同。

## Q6. 指针和引用有什么区别？

**答要点**

1. 引用必须绑定对象，不能为空（语义上）；指针可以为空
2. 引用一经绑定不可再绑到别的对象；指针可改指向
3. 引用没有独立「再分配」语义，用起来像别名；指针是对象
4. 取引用的地址是被引用对象的地址；sizeof 引用是所指类型大小
5. 函数传参：引用避免拷贝且表达「必有对象」；指针表达可选 / 可空

## Q7. `const` 有哪些常见用法？顶层 const 和底层 const？

**答要点**

- 修饰变量：不可修改
- 成员函数后加 `const`：承诺不修改对象逻辑状态（可改 `mutable`）
- 指针：`const T*` / `T* const` / `const T* const`
- **顶层 const**：指针/引用本身不可改；**底层 const**：所指对象不可改
- 与 `constexpr` 对比见下一题

---

## Q8. `const` 和 `constexpr` 区别？

**答要点**

- `const`：运行期常量语义（初始化可在运行期完成）
- `constexpr`：强调编译期可求值（变量、函数、构造等，C++11 起逐步放宽）
- 数组大小、模板非类型参数、`static_assert` 等更常需要 `constexpr`
- C++14/17/20 对 `constexpr` 能力不断增强

---

## Q9. `sizeof` 和 `strlen` 区别？对指针和数组呢？

**答要点**

- `sizeof`：编译期运算符，求类型/对象占用字节数
- `strlen`：运行期函数，数 C 字符串到 `\0` 的长度
- 数组名多数语境退化为指针，但 `sizeof(arr)` 仍是整个数组大小
- 指针的 `sizeof` 是指针本身大小（如 8 字节）

---

## Q10. 深拷贝和浅拷贝？

**答要点**

- **浅拷贝**：只拷贝指针值，多个对象共享同一块资源 → 双重释放风险
- **深拷贝**：拷贝资源内容，各自独立
- 含裸资源的类需正确实现拷贝控制（或禁用拷贝、用智能指针 / Rule of Zero）

---

## Q11. 强制类型转换：C 风格 vs C++ 四种转换？

**答要点**

- `static_cast`：相关类型间的显式转换（上下转换要注意安全性）
- `const_cast`：去/加 const（改真正 const 对象是 UB）
- `reinterpret_cast`：位模式级重解释，危险
- `dynamic_cast`：多态类型安全向下转换，失败指针得 `nullptr`、引用抛异常
- 面试倾向：少用 C 风格强转，意图更清晰、更好搜

---

## Q12. 什么是未定义行为（UB）？举几个 C++ 里的例子

**答要点**

- 标准不规定结果，编译器可任意优化；调试与发布表现可不同
- 例子：解引用空/悬空指针、有符号溢出、数组越界、未初始化读、错误 `delete`、数据竞争（严格说是竞态相关 UB）
- 工程上：开 sanitizer、静态分析、遵守 Core Guidelines

**追问**：未定义、未指定、实现定义行为三者区别？

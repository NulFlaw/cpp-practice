# C++ 大厂面试八股

面向后端 / 基础架构 / 中间件等 **C++ 岗位** 的高频面试问答整理。偏原理与表述，和 `nowcoder/` 里的刷题互补：那边练手写，这边练「说清楚」。

参考来源包括牛客面经、常见大厂考点汇总，以及 [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) 中的工程实践共识。答案用自己的话写，面试时请结合项目经历展开，不要死记。

## 怎么用

1. 打开题库网页（`start-verify.bat` → `http://127.0.0.1:3789/`），右上角切到「八股」浏览
2. 按主题过一遍，能口头讲清「是什么 / 为什么 / 怎么用 / 常见坑」
3. 每题末的「追问」优先准备，面试官常往下挖
4. 能画图的画：内存布局、vtable、控制块、进程地址空间

修改本目录 Markdown 后，执行 `node build-web-data.js` 可刷新根目录 `bagu-data.js`。

## 建议优先级（校招 / 初中级）

**必会**：内存管理、虚函数与虚析构、智能指针、移动语义、vector 扩容与失效、mutex / atomic 基础。

**加分**：内存序、模板/SFINAE、虚继承布局、缓存友好、异常安全等级。
